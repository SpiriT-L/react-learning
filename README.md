# React Learning

Учебный проект для изучения и практики React, включая современные подходы, хуки, маршрутизацию и управление состоянием.

## 📚 Цели проекта

- Освоить основы React: компоненты, props, state
- Изучить React Hooks: useState, useEffect, useContext и др.
- Реализовать маршрутизацию с React Router
- Попрактиковаться в управлении состоянием: Context API, Redux
- Применить TypeScript для типизации компонентов
- Настроить ESLint, Prettier и Husky для автоматизации и качества кода

## 🛠️ Стек технологий

- React 19+
- TypeScript
- React Router
- Redux Toolkit / Context API
- Vite / Webpack
- ESLint + Prettier + Husky

## 📦 Установка

```bash
git clone https://github.com/your-username/react-learning.git
